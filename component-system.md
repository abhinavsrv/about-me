# Interface Component System

**Signal Button.** A primary action is a compact dark-glass button with cloud text, a small right arrow, a signal-ice focus ring, and a 0.97 active scale. A secondary action is a transparent hairline control that becomes a smoke surface on hover.

**Project Capsule.** Each work item is a keyboard-focusable dark panel containing a status label, title, concise evidence-led description, method tags, and an arrow cue. It has a fixed media field and exposes no invented thumbnail metrics. Hover can increase the media scale to 1.015 and brighten the inner rule.

**Status Label.** Research and publication status uses compact, semantic labels such as “First-author manuscript,” “IEEE conference paper — accepted,” “Independent reproduction,” and “Applied ML study.” They must not use generic marketing badges or unqualified publication claims.

**Signal Metric.** Key numeric or categorical information appears as large white values with muted explanatory labels. Metrics only render when the source provides a specific, verifiable value; otherwise the component is omitted.

**Glass Panel.** Raised information units use a `rgba(16,17,18,.72)` background, 1px low-opacity white border, 20px radius, and a restrained inset highlight. The panel never relies on transparency alone where reading contrast would become unstable.
